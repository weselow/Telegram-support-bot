## Описание

Клиент может открыть ссылку и посмотреть историю своей переписки с поддержкой. Ссылка содержит подписанный токен, генерируется по запросу.

## Сценарий использования

1. Клиент привязывает Telegram к веб-сессии
2. В топике/карточке появляется ссылка "Посмотреть историю чата"
3. Клиент переходит по ссылке → видит свою переписку

## API

### Генерация ссылки

```
POST /api/chat/history-link
Authorization: session cookie

Response:
{
  "url": "https://chat.example.com/history?token=<signed_token>",
  "expiresAt": "2025-12-31T12:00:00Z"
}
```

### Просмотр истории

```
GET /history?token=<signed_token>

Token payload (HMAC-SHA256):
{
  "oderId": "uuid",
  "ticketId": "uuid",
  "exp": 1735646400  // Unix timestamp, TTL 24h
}

Response: HTML страница с историей чата
```
