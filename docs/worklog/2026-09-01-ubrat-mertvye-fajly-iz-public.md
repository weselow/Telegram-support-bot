# Убрать мёртвые файлы из public/chat-widget

**Дата:** 2026-09-01
**Задача:** Telegram-support-bot-rvy
**Ветка:** `bd-Telegram-support-bot-rvy`

## Что сделано

Удалены два файла, которые лежали в репозитории без пользы:

- `public/chat-widget/index.html` — старая копия страницы разработчика виджета,
  попавшая в репозиторий из чьего-то локального запуска `dev:serve`;
- `public/chat-widget/themes/chatgpt.css` — собранная копия стиля, исходник
  которой живёт в `chat-widget/src/styles/themes/chatgpt.css`.

Правило в `.gitignore` расширено: теперь игнорируется всё содержимое
`public/chat-widget`, кроме `.gitkeep`. Раньше правила `*.js` и `*.css` не
покрывали ни `index.html`, ни вложенную папку `themes/`, поэтому собранные файлы
и просачивались в репозиторий.

## Почему так

Страница была сломана и до этой задачи, причём тремя способами сразу:
подключала `/chat-widget.js` (сборка отдаётся по `/chat-widget/chat-widget.js`),
вызывала `DellShopChat.init(...)` — такого метода в виджете нет, — и указывала
`apiUrl: 'http://localhost:3500'` на публично отдаваемой странице.

Главное: **на боевой сервер она никогда и не попадала.** `Dockerfile` не
копирует репозиторную папку `public/` в образ совсем — в `public/chat-widget`
кладётся только вывод этапа `widget-builder`. Проверено живьём: `/chat-widget/`
на боевом домене отдаёт 404.

Роль витрины для разработки уже выполняет `chat-widget/dev/index.html`, которая
запускается через `pnpm --filter @dellshop/chat-widget run dev:serve` и после
задачи f6a работает правильно. Второй, сломанной копии не нужно.

## Что проверять первым при поломке

1. **Приложение не стартует, ругается на статику.** `@fastify/static`
   регистрируется с `root: public/chat-widget` (`src/http/server.ts:35`) и падает,
   если папки нет. Её держит `public/chat-widget/.gitkeep` — он намеренно выведен
   из-под правила игнорирования. Если папка пропала, вернуть `.gitkeep`.
2. **Локально виджет не отдаётся.** Собрать его: `pnpm --filter
   @dellshop/chat-widget run build` — скрипт `copy` положит файлы в
   `public/chat-widget/`. В репозиторий они больше не попадут.

## Что осознанно не тронуто

- `public/chat-widget/.gitkeep` — держит папку, нужен для старта приложения.
- `chat-widget/dev/index.html` — рабочая страница разработчика, остаётся.
